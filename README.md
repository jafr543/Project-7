# Advanced Bank Management System - OOP C++

A comprehensive banking system built using **Object-Oriented Programming (OOP)** in C++. The system features a clean text-based user interface and includes all core banking functionalities.

---

## 🌟 Key Features

- **Client Management** (Add, Update, Delete, Find, List, Total Balances)
- **User Management** with advanced **Permissions System**
- **Transactions** (Deposit, Withdraw, Transfer)
- **Transfer Log** (Complete history of money transfers)
- **Login Register** (Track all login attempts)
- **Currency Exchange System** (View, Update rates, Currency Calculator)
- **Security Features** (Password Encryption + Pin Code protection)
- **Clean Architecture** with full separation of concerns

---

## 🛠️ Technologies & Concepts Used

- **Object-Oriented Programming (OOP)**:
  - Encapsulation
  - Inheritance (`clsBankClient` inherits from `clsPerson`)
  - Polymorphism & Abstraction
- Static Member Functions for Business Logic
- Enums for Modes and Permissions
- File Handling (Text file database)
- Advanced Input Validation
- Utility Classes (`clsDate`, `clsString`, `clsInputValidation`)
